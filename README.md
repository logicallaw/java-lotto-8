# java-lotto-precourse: 로또

## 기능 구현
- [x] LottoInputView 구현
  - [x] 로또 구입 금액 입력
  - [x] 당첨 번호와 보너스 번호를 입력
- [x] LottoOutputView 구현
  - [x] 입력 받을 구입 금액 문구 출력
  - [x] 입력 받을 보너스 번호 문구 출력
  - [x] 입력 받을 당첨 번호 문구 출력
  - [x] 입력 받을 보너스 번호 문구 출력
  - [x] 발행한 로또 수량 및 번호 출력
  - [x] 로또 추첨 결과 발표를 안내함
- [x] LottoController: 로또 발행 및 추첨의 전체 실행 흐름 제어
  - [x] Step 1: 로또 구매
    - 사용자로부터 로또 구입 금액을 입력 받는다.
  - [x] Step 2: 로또 발행
    - 구입한 금액만큼 로또를 발행하고 그 결과를 출력한다.
  - [x] Step 3: 로또 추첨
    - 당첨 번호와 보너스 번호를 입력 받는다.
    - 로또를 추첨하여 결과(통계)를 출력한다.
- [x] LottoIssue: 로또 발행
  - [x] 구입 금액으로부터 로또 수량 계산
  - [x] 로또 수량만큼 로또를 발행하여 관리
- [x] 1개의 로또 발행 시, 중복되지 않은 6개의 숫자 추첨
  - Randoms.pickUniqueNumbersInRange(1, 45, 6); 으로 구현
  - 구입 금액에 해당하는 만큼 로또 발행
- [x] 당첨 번호 추첨 시 중복되지 않은 6개와 보너스 번호 1개 추첨
- LottoDraw: 로또 추첨
  - [x] 당첨 금액 관련 Record 정의 (1등~5등에 대한 상금)
  - [x] 사용자가 구매한 로또 번호화 당첨 번호 비교 코드
    - [x] 당첨 내역 및 수익률 계산 코드
- [x] enum LottoErrorMessage 정의
  - "[ERROR] 숫자만 입력 가능해요."
  - "[ERROR] 1,000원 단위만 입력 가능해요." 
  - "[ERROR] 1부터 45사이의 값만 입력 가능합니다."
  - "[ERROR] 로또 번호는 6개여야 합니다."
  - "[ERROR] 쉼표를 기준으로 번호를 구분해주세요."
  - "[ERROR] 모든 로또 번호는 서로 달라야 해요."
  - "[ERROR] 보너스 번호와 당첨 번호는 서로 달라야 해요."
- [x] enum LottoConstant 정의
  - 로또 번호의 최솟값 (1)
  - 로또 번호의 최댓값 (45)
  - 천원 단위 (1000)
  - 나누어 떨어지는 수 (0)
  - 로또 시작 인덱스 (1)
  - 로또 끝 인덱스 (6)
- [x] Lotto 클래스
  - 로또 번호의 유효성 검사
    - 6개의 로또 번호가 서로 다른가?
- [x] 당첨 번호와 보너스 번호를 저장하는 불변 객체(LottoResultsEntered) 정의
  - [x] 입력된 당첨 번호의 유효성 검사
    - 쉼표 구분자를 포함하고 있는가?
    - 정수 값인가?
    - 1부터 45사이의 로또 번호인가?
  - [x] 입력된 보너스 번호 유효성 검사
    - 정수 값인가?
    - 1부터 45사이의 로또 번호인가?
    - 당첨 번호에 보너스 번호를 포함하는가?
